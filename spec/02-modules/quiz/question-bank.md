# Banco obligatorio de preguntas

Los IDs son estables. La columna `Correcta` indica el ID, no la posición visual; las opciones se barajan al iniciar el intento.

## Q1 — Idea de negocio

**Enunciado:** ¿Qué es una idea de negocio?

- `q1-a`: Una propuesta para solucionar una necesidad o problema mediante un producto o servicio.
- `q1-b`: Una actividad sin ningún propósito.
- `q1-c`: Una lista de gastos personales.
- `q1-d`: Una forma de entretenimiento.

**Correcta:** `q1-a`  
**Retroalimentación:** Una idea de negocio busca atender una necesidad o problema mediante una propuesta de valor.
