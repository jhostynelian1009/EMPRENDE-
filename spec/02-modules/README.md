# Módulos y ramas

| Módulo documental | Rama | Skill | Rutas principales | Clave local |
|---|---|---|---|---|
| Aprende | `feature/aprende` | `emprende-aprende` | `(tabs)/aprende`, `aprende/[lessonId]` | `@emprende_plus:aprende` |
| Identidad visual / Inicio | `feature/identidad-visual` | `emprende-identidad-visual` | `_layout`, `(tabs)/_layout`, `(tabs)/index` | ninguna propia |
| Calculadora | `feature/calculadora` | `emprende-calculadora` | `calculadora` | `@emprende_plus:calculadora` |
| Mi Idea | `feature/mi-idea` | `emprende-mi-idea` | `(tabs)/mi-idea` | `@emprende_plus:idea` |
| Quiz | `feature/quiz` | `emprende-quiz` | `quiz/index`, `quiz/resultado` | `@emprende_plus:quiz` |
| Retos | `feature/retos` | `emprende-retos` | `(tabs)/retos`, `retos/[challengeId]` | `@emprende_plus:retos` |
| Mi Proyecto | `feature/mi-proyecto` | `emprende-mi-proyecto` | `(tabs)/proyecto` | ninguna propia |

Las rutas compartidas y los contratos solo se cambian mediante una decisión de integración. Un integrante no debe resolver conflictos editando el módulo de otra persona.
